## Capture Checklist

- Start the app with `npm run backend:dev` and `npm run frontend:dev`.
- Use `http://localhost:3000`.
- Capture desktop screenshots at approximately `1440x900`.
- For admin screens, login as the seeded admin user.
- Keep screenshots updated if the UI changes.
