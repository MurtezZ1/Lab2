# Sunspot Frontend

React + Vite frontend for the Electronic Online Shop.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main Features

- Home page
- Products page
- Product details
- Cart
- Wishlist
- Checkout
- Order history
- User dashboard
- Admin dashboard
- Notifications
- Support tickets
- Redux Toolkit state management
- Protected routes and role-based routes

## API Integration

`src/services/apiClient.ts` configures Axios with JWT access tokens and refresh token retry handling.

Current frontend behavior remains compatible with localStorage services until backend endpoints are connected feature by feature.
